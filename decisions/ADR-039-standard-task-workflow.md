# ADR-039: 标准任务工作流 — 6 阶段主线(调研→实证→判断→处理→检查→汇报)

- **Status**: Accepted
- **Date**: 2026-06-15
- **Decider**: 涛哥
- **Scope**: 跨项目(所有任务的通用执行骨架;统领已有正交工作流 ADR)

> **本 ADR 是编排主线,非新规则** —— 把已有正交 ADR 串成端到端可见主线,各阶段仍以对应下层 ADR 为准。端到端速查在全局 CLAUDE.md「标准任务工作流」段。

---

## Context(背景 / 为什么需要)

工作流各环节早有正交 ADR(① 调研=016 / ② 实证=015 / ③ 判断=018 / ④ 处理=017 / ⑤ 检查=036+008 / ⑥ 汇报=018),但**缺一条把它们串成端到端的可见主线** —— 新会话 / AI / 涛哥无单一总览,易跳步:**跳调研 = 重复造轮子;跳实证 = 臆测;跳检查 = 黑箱/误判完成**。

**实践验证**:2026-06-15 一次治理 session(迁移知识收敛 + 35 ADR 聚类审计 + 全仓索引)完整走了这条主线 —— 先**调研**现有 6 处迁移资产 + 历史 ADR-033/playbook → **实证**读全文 + 跑 37-agent 审计 → **判断**(实证反转「ADR 不该合并」+ 批判「同主题≠合并」)→ **处理**(批次落盘)→ **检查**(CR audit 工具 + 修 MED-1 + 实证 `local=remote`,**抓回了一次 commit 乱码导致的"误判已 push"事故**)→ **汇报**(标 commit + 完结清单)。其中 ⑤ 检查环节正是它抓回了事故,印证"检查不可省"。

**同模式先例**:迁移轨用 [legacy-migration-playbook §0](../standards/legacy-migration-playbook.md) 主线串 ADR-014/028;本 ADR 是通用任务版。

---

## Decision(决策本身)

确立 **6 阶段标准任务工作流主线**,每阶段**编排已有 ADR(不复制其内容)**,含闭环回退:

| 阶段 | 做什么 | 锚(已有 ADR / 机制) |
|---|---|---|
| **① 调研** | 先扫历史 / 现有资产 / 项目地图,不重复造轮子 | ADR-016 + ADR-025 |
| **② 实证** | 拿真证据(`file:line` / 命令 / DB),分实证 vs 假设;上游报告 trust-but-verify | ADR-015 + ADR-030 A3 |
| **③ 判断** | 基于事实给方案 + 批判视角(识真问题,非迎合表面)+ 按授权档汇报 | ADR-018 + ADR-019 |
| **④ 处理** | 按方案落盘,批次自治不打断,跨契约本体先锁 | ADR-017 + ADR-037 + ADR-003 |
| **⑤ 检查** | CR 门禁 + E2E 核对 + 自产复核(连 commit/push 都实证 `local=remote`) | ADR-036 + ADR-008 |
| **⑥ 汇报** | 标来源,完结一次性报告,触线自报 | ADR-018 + ADR-015 |

- **闭环**:⑤ 检查出问题 → 回 ④ 处理;② 实证反转既定前提 → 停回 ③ 升档报涛哥(不带错认知前进)。
- **档位压缩**:简单任务(Tier 1 小改)可压缩(④ 直接做 + ⑤ 自检),但 **① 调研 / ② 实证 / ⑥ 汇报 三步不可跳**(跳 = 重复造轮子 / 臆测 / 黑箱)。

---

## Consequences(影响)

### 正向
- 端到端可见主线;串联正交 ADR 不重复;新会话 / AI 有统一执行骨架。
- 防跳步 —— 尤其防"误判完成"(本 session ⑤ 检查环节即抓回 commit 丢失事故)。

### 负向 / 代价
- 简单任务别教条走全套(用压缩档兜底)。
- 主线是导航非新规则,各环节仍以对应 ADR 为准(避免与下层重复)。

### 影响范围
- 全局 `CLAUDE.md` 顶部加精炼主线表 + 指针(ADR-009 cheatsheet 风格)。
- `decisions/README` 归「治理元方法」簇。

---

## Alternatives Considered

- **A. 新建大 ADR 复制各环节细则** — 否:制造与 015/016/017/018/036/008 重复,违反 2026-06-15 聚类审计确认的「正交不合并」精神。
- **B. 纯写全局 CLAUDE.md 详述** — 否:违反 ADR-009(CLAUDE.md 薄)+ ADR-033(准入三闸:详细下沉 ADR)。
- **C. 编排主线 ADR + CLAUDE.md 精炼指针(选)** — 串联不复制,符合治理金字塔。
